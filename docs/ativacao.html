Ativar licença — CaraCore Seed

Controle de licenças preso ao sistema operacional e à placa-mãe do computador. Respeitamos a LGPD.

  1. Faça o pagamento de R$ 29,00 via PIX (Cara Core Informática, CNPJ) na página de compra.
  2. Instale o CaraCore Seed no seu computador. Ao abrir o aplicativo sem licença, será exibida a tela Licença necessária com o ID de Ativação (vinculado a este computador). Clique em Copiar ID de Ativação.
  3. Envie o comprovante de pagamento PIX e o ID de Ativação (colado) para a Cara Core Informática pelo canal de feedback: e-mail suporte@caracore.com.br, WhatsApp 55 41 9 9909-7797 ou Telegram. Não atendemos ligações telefônicas.
  4. Você receberá o arquivo license.key. Coloque-o na pasta de dados do aplicativo (ex.: %APPDATA%\caracore-seed-desktop\license.key no Windows) ou na mesma pasta do executável. Reinicie o CaraCore Seed — o aplicativo será liberado.

Onde colocar o license.key

Windows (instalado): %APPDATA%\caracore-seed-desktop\license.key

Windows (portátil): na mesma pasta do arquivo caracore-seed.exe, crie ou cole o arquivo license.key.

Reinicie o aplicativo após colocar o arquivo.

LGPD: O ID de Ativação é anônimo (não contém nome, CPF ou e-mail). Usamos apenas para gerar a licença vinculada ao seu computador. A associação com você fica apenas no controle da Cara Core para entrega da licença e suporte. Não revendemos dados.
