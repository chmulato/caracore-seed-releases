Primeiro acesso ao piloto

O CaraCore Seed é gratuito e licenciado sob MIT; não exige licença para ser usado. O código-fonte ainda não está publicamente acessível.

Conta administrativa local

Na primeira execução, a conta local é admin com senha inicial admin. Antes de acessar o painel, informe admin como senha atual e escolha uma senha nova de exatamente 8 caracteres, repetindo-a no campo de confirmação.

A janela do primeiro acesso também mostra uma chave de recuperação. Copie-a antes de fechar e guarde-a num local seguro fora deste computador. Ela permite redefinir a senha; não a partilhe por e-mail ou chat. A chave só é exibida uma vez. Após uma recuperação, a chave usada é invalidada e uma nova chave é apresentada.

As credenciais e os dados ficam no perfil local do usuário. Se perder a senha, use a opção de recuperação com a chave guardada; não apague manualmente admin-credentials.json nem o banco de dados.

O Seed não envia dados para um serviço de ativação e não tem checkout ou cobrança.
