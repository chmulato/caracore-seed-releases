Integração com o CaraCore Seed

Visão geral para desenvolvedores que integram a validação de licenças aos próprios programas.

Antes de integrar: limite importante da versão 0.1.3

O servidor atende apenas em 127.0.0.1, mas a API local /api/v1 não exige autenticação. Qualquer programa executado no mesmo computador pode criar ou revogar licenças. Essa limitação está prevista para correção na versão 0.1.4. Não use a versão 0.1.3 em produção.

Onde consultar a API

Com o Seed em execução no computador, abra Swagger UI local. A API usa a porta 9080 nesta versão. O servidor não é exposto à rede local.

Use o Swagger local como referência para as rotas, parâmetros e respostas disponíveis na versão instalada. A documentação pública disponível para 0.1.3 não especifica os códigos de erro nem o contrato completo dos endpoints; não presuma nomes de campos ou códigos fora do que o Swagger apresenta.

Verifique a assinatura offline

A assinatura da licença usa SHA256withRSA. A chave pública está em security/license-public.pem. O programa cliente pode verificar a assinatura sem consultar a API ou a internet, desde que tenha os bytes exatos assinados e a assinatura codificada em Base64.

Importante: a documentação pública da versão 0.1.3 não define o esquema JSON da licença nem a serialização/canonicalização assinada. O exemplo abaixo mostra a operação criptográfica, não o formato da licença: obtenha do payload e da resposta de validação no Swagger os campos reais e preserve exatamente os bytes assinados. Não reserialize o JSON antes de verificar.

Java

import java.nio.file.Files;
import java.nio.file.Path;
import java.security.KeyFactory;
import java.security.PublicKey;
import java.security.Signature;
import java.security.spec.X509EncodedKeySpec;
import java.util.Base64;

byte[] payloadBytes = obterBytesExatosDoPayloadAssinado();
byte[] assinatura = Base64.getDecoder().decode(assinaturaBase64);

String pem = Files.readString(Path.of("security/license-public.pem"));
String base64Key = pem
    .replace("-----BEGIN PUBLIC KEY-----", "")
    .replace("-----END PUBLIC KEY-----", "")
    .replaceAll("\\s", "");
byte[] keyBytes = Base64.getDecoder().decode(base64Key);
PublicKey chave = KeyFactory.getInstance("RSA")
    .generatePublic(new X509EncodedKeySpec(keyBytes));

Signature verifier = Signature.getInstance("SHA256withRSA");
verifier.initVerify(chave);
verifier.update(payloadBytes);
boolean assinaturaValida = verifier.verify(assinatura);

Python (pacote cryptography)

from base64 import b64decode
from pathlib import Path
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding

payload_bytes = obter_bytes_exatos_do_payload_assinado()
assinatura = b64decode(assinatura_base64, validate=True)
chave = serialization.load_pem_public_key(
    Path("security/license-public.pem").read_bytes()
)

chave.verify(
    assinatura,
    payload_bytes,
    padding.PKCS1v15(),
    hashes.SHA256(),
)
# Se verify() terminar sem InvalidSignature, a assinatura confere.

Uma assinatura válida confirma que os bytes foram assinados com a chave privada correspondente. O cliente também deve verificar validade, produto, cliente e limites conforme os campos definidos pelo Seed e pelas regras do seu próprio programa. Proteja a chave privada: perder security/license-private.pem impede emitir novas licenças compatíveis.

Sinal periódico (heartbeat)

O programa licenciado pode enviar um sinal periódico de uso à API local. Os campos conhecidos incluem usuariosAtivos (quantidade de usuários ativos), status (estado do programa) e timestamp (data e hora do registro). Confira no Swagger da instalação o endpoint, os tipos, os valores aceitos e eventuais campos obrigatórios.

{
  "usuariosAtivos": 12,
  "status": "<estado aceito pela API>",
  "timestamp": "<data e hora aceitas pela API>"
}

Os registros são locais; a versão 0.1.3 não oferece monitoramento remoto de heartbeats.
