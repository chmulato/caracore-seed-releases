CaraCore Seed — piloto gratuito sob MIT

Licença MIT. Não há compra, checkout ou ativação paga.

O piloto é gratuito e licenciado sob MIT; não há compra, checkout nem ativação paga. O código está sob MIT, mas a oficina ainda não está publicamente acessível.

O candidato Windows x64 0.1.3 está disponível para avaliação gratuita, mas ainda aguarda homologação independente e teste em perfil limpo. Não o considere pronto para produção. Baixar o instalador Windows x64; confira o SHA-256 na página de distribuição. Linux fica fora desta etapa; o instalador é unsigned.

O Seed guarda os dados no computador local e não oferece monitoramento remoto de heartbeats. Para dúvidas ou feedback, use o canal de feedback.
