# Assets da loja CaraCore Seed

Todas as páginas HTML da loja utilizam os recursos desta pasta:

- **css/** — Estilos compartilhados
  - `portal-style.css` — Portal (portal-controle, tecnologia, readme)
  - `seed-loja.css` — Tema escuro (index, ativacao, download, canal-feedback, compra)
- **js/** — Scripts compartilhados
  - `seed.js` — Carregado em todas as páginas
- **img/** — Imagens da loja (utilize caminhos `assets/img/` nas páginas)
