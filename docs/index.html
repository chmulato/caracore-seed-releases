CaraCore Seed

Cadastre clientes, emita licenças assinadas e integre a validação ao seu próprio programa — tudo localmente.

Como funciona

  1. Cadastre o cliente e os dados da licença no painel do Seed.
  2. Emita uma licença assinada para o seu produto e cliente.
  3. Valide no seu programa a assinatura e as regras da licença; o programa também pode enviar um sinal periódico de uso (heartbeat) à API local.

O Seed guarda os registros no SQLite do computador. O servidor local escuta em 127.0.0.1 e não oferece painel remoto.

No ecossistema Cara Core, o Seed é uma ferramenta complementar de gestão local de clientes e licenças. Cada produto continua com seu próprio aplicativo, acesso e banco; o Seed não centraliza dados dos demais produtos.

Para quem é

Desenvolvedores e pequenas software houses que precisam cadastrar clientes, emitir licenças para seus programas e validar essas licenças no próprio software.

O Seed inclui cadastro de clientes, emissão e administração de licenças, consulta de validade, auditoria e alertas. O próprio Seed é gratuito e não exige uma licença de uso.

Guia de integração Documentação funcional

Pré-release candidata — versão 0.1.5

O instalador Windows x64 está publicado para avaliação como pré-release. Esta atualização corrige problemas de segurança e robustez: valida Host em todas as rotas, renova o token CSRF após login e troca de senha, e distingue licenças revogadas/expiradas quando o token é válido. Ainda falta homologação independente; não considere o piloto pronto para produção. O instalador não tem assinatura digital e Linux não faz parte desta versão.

Heartbeats usam a hora UTC do servidor, preservando a hora do cliente para diagnóstico. A migração SQLite V8 mantém bancos 0.1.3/0.1.4 e as chaves existentes; respostas documentam o payload RSA exato. O Swagger UI carrega documentação local, sem CDN ou validador externo.

A API administrativa exige sessão e proteção CSRF; as rotas de integração usam token por licença. O servidor verifica sua identidade e escolhe uma porta local disponível. Licenças antigas podem precisar de emissão ou rotação do token para usar as rotas protegidas.

O binário e o texto da licença são MIT. O código-fonte não está publicado; uma data para publicação ainda não foi definida. Não há checkout nem pagamento real.
