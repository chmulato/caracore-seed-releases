Canal de feedback — CaraCore Seed

Dúvidas e feedback sobre o CaraCore Seed. Use os canais abaixo para relatar problemas ou sugerir melhorias.

Não atendemos ligações telefônicas. Use e-mail, WhatsApp ou Telegram.

Como relatar um problema: envie um e-mail com o assunto "CaraCore Seed — piloto Windows" e inclua:

  • Versão do Seed;
  • Versão do Windows (10 ou 11, e se é 64 bits);
  • etapa em que ocorreu o problema e os passos para reproduzi-lo;
  • mensagem de erro e, se necessário, o trecho relevante de server.log.

O log fica na pasta de dados local do Seed, sob %APPDATA%\CaraCore Seed\. Remova dados pessoais antes de compartilhar. Nunca envie senhas, chaves privadas, chave de recuperação ou arquivos de banco completos.
