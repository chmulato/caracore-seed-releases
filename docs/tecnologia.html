Tecnologia local

Piloto desktop local: candidato Windows x64 0.1.3 disponível para avaliação; homologação independente e teste em perfil limpo pendentes. Linux fica fora desta etapa.

Shell desktop: Electron

O desktop usa Electron; a etapa inicial de distribuição é restrita a Windows x64. Linux x64 depende de build e smoke em ambiente nativo. A interface roda em uma janela nativa; o backend Java inicia localmente e só aceita conexões em 127.0.0.1.

Backend: Java (JAX-RS + JPA)

O núcleo de regras de negócio e API REST é em Java 25 (JAX-RS, JPA). O instalador inclui um runtime reduzido e o launcher inicia o WAR em Tomcat 10.1 embarcado; o usuário não precisa instalar Java.

Persistência: SQLite

Os registros de licenças e clientes ficam em banco SQLite no perfil local do usuário. O piloto não depende de banco de dados remoto. Faça backup do arquivo de banco com o aplicativo fechado.

Plataformas previstas: Windows e Linux x64

O pacote NSIS para Windows 10/11 x64 foi publicado como piloto para avaliação na versão 0.1.3; a homologação independente continua pendente. Os pacotes AppImage e .deb para Linux x64 ficam para uma etapa posterior, após build e smoke nativos. O instalador Windows não tem assinatura digital.

API REST local e telemetria

A API REST é acessível somente localmente em 127.0.0.1. Heartbeats são registros recebidos pelo aplicativo local; não há comunicação de monitoramento remoto nem acesso pela rede nesta etapa.

Portal de controle e LGPD

O piloto armazena registros localmente. O operador é responsável por proteger o computador, as credenciais administrativas, os backups e quaisquer dados pessoais inseridos, observando os requisitos aplicáveis da LGPD.

Escopo piloto: gestão local de clientes e licenças. Não há serviço em nuvem, pagamento real, PIX ou integração externa; o gateway de pagamentos é apenas um stub para testes.
