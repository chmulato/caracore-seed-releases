Estado da distribuição — CaraCore Seed

Piloto local gratuito sob MIT; candidato Windows em homologação fechada.

O CaraCore Seed é um piloto local gratuito sob licença MIT. Não há checkout, pagamento ou ativação paga. O código-fonte é licenciado sob MIT, mas a oficina ainda não está publicamente acessível.

O candidato Windows x64 0.1.3 passou nos testes automatizados. A homologação independente e a instalação/uso em perfil limpo ainda estão pendentes. Nenhum instalador foi enviado ou publicado; esta página não oferece arquivo para download.

A etapa planejada é um piloto fechado por convite no Windows. Linux fica fora desta entrega até ter build e smoke em runner Linux nativo. Os instaladores desta etapa serão unsigned; não desative as proteções do sistema operacional.

O aplicativo mantém dados no SQLite local e não oferece monitoramento remoto de heartbeats. Para solicitar participação, fale com a Cara Core pelo canal de convite.
