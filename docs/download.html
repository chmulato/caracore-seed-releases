Requisitos

  • Windows 10 ou Windows 11, 64 bits (x64).
  • Instalador de aproximadamente 219 MB; cerca de 400 MB de espaço após a instalação.
  • Java já vem incluído; não instale Java separadamente para usar o Seed.
  • O Seed escolhe uma porta local disponível ao iniciar; não é necessário reservar a porta 9080.
  • O requisito mínimo de memória RAM não foi confirmado para esta versão.

Segurança e estado da pré-release candidata 0.1.5

A API local exige autenticação: ações administrativas usam sessão ADMIN com proteção CSRF, e as rotas de integração de cada licença usam um token próprio. O Host é validado em todas as rotas; o token CSRF muda após login e troca de senha. O servidor continua vinculado a 127.0.0.1, escolhe uma porta local disponível e verifica sua identidade.

A versão 0.1.5 registra heartbeats no horário UTC do servidor e marca desvios do relógio do cliente; um token válido para licença revogada/expirada recebe o respectivo status. O banco da 0.1.3 e 0.1.4 é migrado com Flyway V8 aditiva, preservando dados, chaves RSA e assinaturas. O Swagger UI usa documentação servida localmente, sem CDN nem validação remota.

A versão 0.1.3 tinha uma API sem autenticação e foi substituída; a 0.1.4 é a release estável anterior. A 0.1.5 continua sendo pré-release candidata para avaliação: homologação independente ainda está pendente. Não a considere homologada nem pronta para produção. O instalador não tem assinatura digital; Linux não faz parte desta versão.

Instalação e aviso do SmartScreen

  1. Baixe o instalador e confira se ele tem 216.466.586 bytes.
  2. Calcule o SHA-256 do arquivo e compare com o valor publicado acima, antes de executá-lo.
  3. Se o SmartScreen avisar que o aplicativo não é reconhecido, confira novamente tamanho e hash. Só então, se decidir prosseguir, escolha Mais informações e Executar assim mesmo.

Não desligue o SmartScreen, o Defender nem outras proteções do Windows. Se o tamanho ou o hash não corresponder, não execute o arquivo.

Onde ficam seus dados

O banco SQLite, as chaves e os registros do aplicativo ficam no perfil do usuário, sob %APPDATA%\CaraCore Seed\. A porta escolhida pelo servidor é registrada em %APPDATA%\CaraCore Seed\server\server.port. Não compartilhe o banco nem arquivos de chave em pedidos de suporte.

Antes de usar com clientes reais: backup e recuperação

  • Faça uma cópia de segurança pelo recurso de backup do Seed e guarde o arquivo .seedbackup em outro dispositivo ou local seguro.
  • Guarde a chave de recuperação fora deste computador. Ela é diferente do arquivo da chave privada usado para assinar licenças.
  • Não apague nem substitua o banco SQLite ou as chaves. Perder security/license-private.pem impede a emissão de novas licenças que correspondam às assinaturas existentes.
  • Para recuperar os dados, use o recurso de restauração do próprio Seed com o arquivo .seedbackup. Faça um backup recente antes de testar a restauração.

Faça backup antes de atualizar. Não desinstale removendo os dados: preserve o banco SQLite e as chaves de assinatura. A rotina de backup/restauração ainda não passou por todas as regressões manuais; mantenha cópias independentes.

Como integrar

O guia de integração da API e validação de licenças descreve o uso local e a verificação da assinatura. A porta atual é dinâmica; consulte %APPDATA%\CaraCore Seed\server\server.port e abra http://127.0.0.1:<porta>/swagger-ui enquanto o Seed está em execução.

Ajuda e feedback

O Seed é gratuito e não tem ativação paga. Consulte as instruções de primeiro acesso. Para relatar um problema, use o canal de feedback. Não envie senhas, chaves privadas ou a chave de recuperação.
