Documentação

Visão, requisitos e links oficiais do CaraCore Seed.

O que é o CaraCore Seed?

Piloto local gratuito sob licença MIT para cadastro de clientes e gestão de licenças. O desktop usa Electron, backend Java 25, Tomcat embutido e SQLite. O candidato Windows x64 0.1.4 está disponível para avaliação, mas aguarda homologação independente e regressões manuais completas. Linux fica fora desta entrega.

O escopo inclui gestão e validação de licenças, validade, alertas, auditoria e registros locais de heartbeats recebidos. O Seed não exige ativação para uso, não integra cobrança real e não oferece monitoramento remoto. O backend fica vinculado a 127.0.0.1, usa porta local dinâmica e protege operações administrativas com sessão/CSRF e operações de licença com token. O acesso público ao código-fonte ainda não foi confirmado.

Requisitos

  • Piloto público para avaliação: Windows 10/11 x64; Linux x64 depende de build e smoke nativos
  • Os pacotes planejados incluem runtime Java 25 e não exigem Java instalado
  • Não exige servidor de banco de dados — usa SQLite local
  • O uso local não exige conexão com serviços de nuvem; os recursos web são incluídos no pacote

Links úteis

  • Releases e instaladores — acompanhe futuras publicações de pacotes e checksums.
  • Código-fonte — licenciado sob MIT, mas ainda sem publicação pública confirmada.
Disponibilidade: candidato Windows 0.1.4 para avaliação sob MIT, ainda sem homologação. Consulte o estado da distribuição e SHA-256; instalador unsigned. Contacto: suporte@caracore.com.br · portfólio.
Dados locais: o administrador é responsável por proteger os dados inseridos, os backups e o computador onde o banco SQLite fica armazenado.
