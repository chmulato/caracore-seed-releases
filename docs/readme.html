Visão, requisitos e links oficiais do CaraCore Seed.

O que é o CaraCore Seed?

Ferramenta de uso interno da Cara Core Informática: gestão de licenças para aplicações do ecossistema que rodam no Windows. Inclui o aplicativo desktop (Electron, 100% offline) e o portal de controle das licenças, com transparência e respeito à LGPD — inspirado na mesma filosofia do chmulatoETE Minerador 4.0.

É o Contador de Licenças usado pela Cara Core para governança do ecossistema (PDV, Minerador 4.0, Reino OIDC, Hub). A aplicação não está disponível para download nem à venda.

Requisitos

  • Windows 10 ou 11 (64 bits)
  • Java 17 (se o instalador não incluir runtime embarcado)
  • Não exige servidor de banco de dados — usa SQLite local
  • Não exige internet para operação diária

Links úteis

  • caracore-seed-releases — Repositório público de releases e instalador.
  • Releases — Versões e CHANGELOG.
